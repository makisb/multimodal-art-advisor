# 🎨 ART Advisor

## Overview

ART Advisor is a multimodal artwork analysis and recommendation system built using deep learning and CLIP embeddings.

The project combines visual understanding of artworks with emotion recognition to predict artistic attributes such as style, genre, artist, and emotional impact. It leverages the WikiArt and ArtEmis datasets and provides an interactive Gradio interface for artwork analysis.

## Features

- Artwork style classification
- Artist prediction
- Genre classification
- Emotion recognition
- CLIP-based image embeddings
- Interactive Gradio interface
- Multi-task deep learning framework

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
jupyter notebook ART_ADVISOR.ipynb
```

Run the notebook cells sequentially and launch the Gradio interface.
